# 顺风方块 / Arrow Garden 美术素材交接（v1）

本包为 AI 生成的视觉母版与界面验收素材。每个可复用对象单独存为 PNG；包括 85 张 PNG：背景 3、面板 3、按钮 11、图标 9、方块 40、已认可绿色 L 形材质参考 1、箭头 8、反馈与特效 8、页面预览 2。逐文件的实际尺寸、色彩模式、透明通道与用途见 `asset_manifest.csv`。背景及页面预览为 RGB 不透明图片；其余 PNG 具有真实 alpha 通道及透明像素。透明通道不代表边缘已达到上线质量。

## 内容

- `backgrounds/`：首页、对局、备用花园背景；为手机竖屏设计，按界面安全区适配。
- `panels/`：棋盘托盘、顶部信息面板、提示条；需要按实际画面测试裁剪、缩放及九宫格参数。九宫格尚未验证。
- `buttons/`：绿色主按钮、奶油色次按钮、圆形按钮各有 normal/pressed/disabled；顶部小按钮有 normal/pressed。图标与文字独立叠加。
- `icons/`：设置、返回、首页、重来、提示、暂停、播放、章节、每日挑战图标。
- `blocks/`：`block_<颜色>_<形状>.png`，五色各八形，无箭头；`reference_approved_green_L.png` 是既有材质参考，不是当前逻辑方向模板。`shapes_manifest.json` 保存用户提供的游戏形状坐标。
- `arrows/`：四方向独立白色箭头及 alt 备用版本。
- `effects/`：星星、花瓣、光效、成功/失败徽章。
- `previews/`：生成式首页及对局概念图，仅供美术风格参考，并非 Cocos 实机截图；图中文字与方块布局不代表游戏真实内容或玩法。

## Cocos 交接及待处理事项

1. 方块的每格像素大小、透明留白、视觉中心及阴影范围并不统一，不能按图片原尺寸直接当作网格规格。请依据游戏实际 cells、统一网格尺寸及锚点重新处理并在棋盘内验收，避免重叠、越格或间隙；必要时按精确模板重做蒙版。
2. 根据用户提供的逻辑：`lleft` 右上角为空、`lright` 左上角为空，坐标原点为左下；本批方块方向已按上述目标作目视及粗略透明采样核对，尚未完成像素级几何验证。旧素材曾有旋转补偿，接入时需要与代码现状共同核对，避免重复旋转。
3. 一些图片边缘存在彩色杂点或过宽光晕，部分箭头与图标较明显；需清理透明边缘、检查浅深色背景及缩小后的可读性。各按钮状态的画布、轮廓、视觉中心不完全一致，需要统一后才适合直接切换。
4. 箭头、图标、文字由 Cocos 单独叠加。注意浅色方块上的对比度。面板及按钮的拉伸边距必须以实图检查，避免圆角变形。注意透明边缘、图片压缩及多种手机屏幕的安全区。
5. 本包尚未在 Cocos Creator 3.8.8 中组装、构建或真机测试，不能声明为已通过正式生产验收的资产。颜色、光照和边缘效果仍需统一检查。
